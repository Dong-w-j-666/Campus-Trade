# Campus-Trade 轻量服务器部署说明

适用于 Ubuntu 24.04、2 核 2 GB 以上的阿里云或腾讯云轻量应用服务器。

## 1. 初始化系统

登录服务器终端后执行：

```bash
sudo apt update
sudo apt -y upgrade
sudo apt -y install git curl openssl
```

为 2 GB 内存的服务器增加 2 GB 交换空间：

```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

检查交换空间：

```bash
free -h
```

如果系统提示需要重启，可以执行 `sudo reboot`，随后重新连接远程终端。

## 2. 安装 Docker

```bash
curl -fsSL https://get.docker.com | sudo sh
sudo systemctl enable --now docker
sudo usermod -aG docker "$USER"
```

退出远程终端并重新连接，然后检查：

```bash
docker --version
docker compose version
```

## 3. 获取项目

```bash
cd "$HOME"
git clone https://github.com/Dong-w-j-666/Campus-Trade.git
cd Campus-Trade
```

## 4. 生成生产配置

```bash
chmod +x scripts/setup-production-env.sh
./scripts/setup-production-env.sh
```

脚本会生成仅服务器可见的 `.env.production`，其中包含随机数据库密码和登录签名密钥。不要提交、截图或发送该文件。

## 5. 启动应用

```bash
docker compose --env-file .env.production \
  -f docker-compose.production.yml up -d --build
docker compose --env-file .env.production \
  -f docker-compose.production.yml ps
```

首次构建需要下载 Maven、JDK 和 MySQL 镜像。2 GB 内存的服务器已经配置交换空间，构建可能比本机慢。

查看日志：

```bash
docker compose --env-file .env.production \
  -f docker-compose.production.yml logs -f app
```

按 `Ctrl+C` 只会退出日志查看，不会停止容器。

## 6. 临时通过 IP 验收

云服务器安全组只需临时开放 `8080`，然后访问：

```text
http://服务器公网IP:8080
```

不要开放 MySQL 的 `3306` 或宿主机 `13306`。生产 Compose 没有映射 MySQL 公网端口。

## 7. 绑定域名和 HTTPS 前

正式启用反向代理前，把 `.env.production` 调整为：

```dotenv
APP_BIND_ADDRESS=127.0.0.1
APP_HOST_PORT=8080
APP_SECURE_COOKIE=true
```

反向代理只从本机访问 `127.0.0.1:8080`，公网仅开放 `80` 和 `443`。大陆服务器的域名解析前需要完成 ICP 备案。

## 常用运维命令

```bash
# 查看容器状态
docker compose --env-file .env.production -f docker-compose.production.yml ps

# 查看最近 200 行应用日志
docker compose --env-file .env.production -f docker-compose.production.yml logs --tail=200 app

# 重启应用
docker compose --env-file .env.production -f docker-compose.production.yml restart app

# 停止容器并保留数据库与上传文件
docker compose --env-file .env.production -f docker-compose.production.yml down

# 更新代码后重新构建
git pull --ff-only
docker compose --env-file .env.production -f docker-compose.production.yml up -d --build
```
